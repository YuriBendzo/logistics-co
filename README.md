# LogisticsCo – Global Freight & Shipping

Modern, responsive website for a global logistics and freight forwarding company.  
Built with performance and clean code in mind.

[LogisticsCo Preview](https://yuribendzo.github.io/logistics-co/)

## ✨ Features

- Fast & lightweight – powered by **Vite**
- No frameworks → pure **Vanilla JavaScript** + modular structure
- Modern styling with **SCSS** (variables, mixins, nesting, BEM-like methodology)
- Fully responsive design (mobile-first)
- Smooth animations & interactions
- Contact form (static or ready for backend integration)
- SEO-friendly structure
- Optimized production build (minified JS/CSS, image optimization ready)

## 🛠️ Tech Stack

| Technology       | Purpose                              |
|------------------|--------------------------------------|
| Vite             | Lightning-fast dev server & build tool |
| Vanilla JS       | Core logic, DOM manipulation, modules |
| SCSS             | Advanced CSS with variables & mixins  |
| HTML5            | Semantic markup                      |
| ES Modules       | Modern JavaScript organization       |
